# 📚 REST API, ACID ও DDD — Professional Backend Series (বাংলায়)

এই সিরিজে তিনটি গুরুত্বপূর্ণ backend ধারণা সহজ বাংলায় ব্যাখ্যা করা হয়েছে — **কী**, **কেন**, **কীভাবে কাজ করে**, **কোন পরিস্থিতিতে লাগে**, এবং **professional project-এ কীভাবে ব্যবহার হয়**।

কোড উদাহরণগুলো **ASP.NET Core (C#) + SQL Server** দিয়ে দেওয়া হয়েছে।

## 🎯 কীভাবে পড়বেন

1. প্রথমে **REST** — client আর server কীভাবে কথা বলে
2. তারপর **ACID** — data কীভাবে নিরাপদ থাকে
3. তারপর **DDD** — business logic কীভাবে সাজাবেন
4. শেষে **Chapter ০৪** — তিনটি একসাথে একটি real উদাহরণে

## 🧰 Prerequisites

- C# ও ASP.NET Core-এর basic ধারণা
- SQL (SELECT, INSERT, UPDATE) জানা
